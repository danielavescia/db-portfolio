# Projeto de Portfólio DB

Portfólio pessoal desenvolvido em html e css para apresentação de projetos, habilidades e informações profissionais.

# Principais Funcionalidades
* Seção “Sobre”: Exibe informações pessoais como nome, cargo atual, foto, descrição e nível de habilidades
* Listagem de projetos: Apresenta projetos em formato de galeria com nome, descrição, tecnologias utilizadas e links para repositório
* Acesso ao currículo: Permite visualizar o currículo em PDF em uma nova aba diretamente pelo menu.
* Links de contato: Disponibiliza acesso rápido ao GitHub, LinkedIn e e-mail pelo cabeçalho da aplicação.
